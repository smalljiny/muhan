07-30 기준 — 게임 command 디스패처 + 연마(train) 배선 #106(PR #125)과 character.flags 스키마 #117(PR #127)이 머지됐습니다. PROTOCOL_VERSION 3. 열린 PR 0 · 활성 worktree 0 · 작업 트리 clean — 착수 대기 상태이고, 막힌 항목은 없습니다. 다만 라이브에 진입한 train이 #124(재접속 시 진행도 무성 revert)에 노출됐습니다.
